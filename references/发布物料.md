## 三、最终口播稿

保留可直接拍摄的纯净稿，必要时另附：

- 分段提词位置；
- 动作、现场、B-roll 或素材建议；
- 字幕重点；
- 节奏与停顿；
- `【待补充】` 的真实事实。

不要把分析说明混进出镜正文。

## 五、评论与承接

- 置顶评论：延续正文、补充细节或提出自然问题；
- 普通互动回复：2—3 条；
- 质疑回复：需要时提供；
- 高意向识别：本条若涉及业务，说明什么评论属于高意向；
- 私信首轮回复：仅 2 级内容或用户明确要求承接时提供。

0 级内容不生成销售私信话术；1 级内容通常只做自然评论互动；2 级内容一次只给一个下一步，不发送大段服务介绍。

## 六、最终自审

逐项给结论，不写空泛“没问题”：

- 标题是否兑现；
- 前段观看理由；
- 每段信息增量；
- 真实证据与待补事实；
- 人设和能力边界；
- 真人口语与拍摄难度；
- 业务露出是否符合等级；
- 广告感：低 / 中 / 高及原因；
- 极限词、结果承诺、敏感行业和平台风险；
- 是否建议进入拍摄。

## 七、模板测试与发布后记录

预先写明本条验证假设、测试变量和主要指标。例如：

- 流量型：验证开头是否提高目标人群停留；
- 信任型：验证真实现场是否带来有效评论、收藏、关注或主页访问；
- 转化型：验证某一购买顾虑是否带来高意向私信。

并记录：

- 内容模板：场景冲突 / 工作现场 / 客户问答 / 案例复盘 / 观点判断 / 经历故事等；
- 本次只测试的变量：开头 / 标题 / 证明方式 / 拍摄形式 / 结尾承接；
- 目标用户是否实际出现：用评论、主页访问、私信或咨询判断；
- 对照基线：同账号、同平台、同内容任务近 5—10 条；没有则标缺失；
- 下一轮保留或替换哪个变量。

每轮尽量只改 1—2 个变量。发布后用同账号、同平台、同类型基线复盘，不使用固定万能阈值。
