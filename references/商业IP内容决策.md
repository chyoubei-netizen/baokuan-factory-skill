# 商业 IP 内容决策

本文件用于 Mode B 的商业判断。它是过滤层，不是第三种模式，也不要求每条视频带业务。

## 1. 先分清三个层级

### 内容主任务

每条只定一个主要任务：

- **流量型**：让更多合适的陌生人停留、观看或进入主页。不是越泛越好，而是扩大目标相关人群。
- **信任型**：让人形成可信判断。分为人格信任与专业信任。
- **转化型**：为有明确需求、正在比较或临近决策的人消除顾虑，并引导一个自然下一步。

### 信任子类型

- **人格信任**：观众认同这个人的经历、价值观、态度、做事原则和边界。
- **专业信任**：观众看到具体判断、过程、案例、细节和解决问题的能力。

人格信任不等于空泛观点；专业信任也不等于上课。二者都可以完全不出现销售话术。

### 素材形态

观点型、价值观型、案例型、工作现场型、方法型、经历型、复盘型只是“用什么材料来讲”。例如：

- 流量型 × 观点型；
- 信任型（人格）× 经历型；
- 信任型（专业）× 工作现场型；
- 转化型 × 案例型。

不要把这些标签混成五到八种互相排斥的内容类型。

## 2. 业务露出三级判断

### 0 级：无业务露出

适用：

- 个人经历、价值观、生活观察或行业之外的相关观点；
- 目的是建立人格信任；
- 业务连接生硬，加入后会破坏内容；
- 账号需要保持人物丰富度，而不是每条都偷偷销售。

执行：正文不提服务，不加咨询 CTA。只检查观点是否符合项目长期人设和风险边界。

输出标注：`业务连接：无，保持纯观点，不强行植入。`

### 1 级：自然显能

适用：

- 内容来自真实工作现场、客户问题、剪辑过程或行业观察；
- 一个专业判断本身就是内容价值；
- 观众还处于认识和相信阶段。

执行：只让一项能力通过场景、动作或判断被看见，例如“会把老板口述整理成可拍内容”或“会判断参考视频是否适合业务”。不要列服务清单，也不要突然自我介绍。

常见入口：

- 最近拍一个客户时，我发现……
- 客户发来一条参考视频，我没直接开拍，因为……
- 昨天改一条口播，我删掉最多的不是废话，而是……

这些只是入口功能，不要求逐字使用。没有真实经历时不能伪装成“最近的客户”。

### 2 级：轻转化

适用条件至少满足一项：

- 用户明确要求本条承担咨询、预约或成交；
- 选题直接回答目标客户在比较和决策阶段的顾虑；
- 有真实案例、过程、服务边界或结果证据支撑；
- 账号内容排期需要一条承接已有信任的内容。

执行：正文先解决问题，再说明适合/不适合谁、合作前需准备什么或如何判断服务；结尾只给一个低压力下一步。不能靠“私信我”弥补正文没有信任证据。

不满足证据条件时，把它降为 1 级专业信任，先补过程和判断。

## 3. 什么时候算“需要获客约束”

商业项目的所有内容都要遵守人设、受众和事实边界，这叫“项目一致性”；只有 1—2 级内容才需要正文里的业务连接，这叫“商业露出”。两者不能混为一谈。

以下情况启用商业露出判断：

- 用户明确说要获客、咨询、成交、介绍业务、软广或转化；
- 原始素材天然来自业务现场；
- 选题与目标客户的购买顾虑、服务流程或判断标准直接相关；
- 当前内容计划缺少专业证据或转化承接。

以下情况默认不植入：

- 纯人格观点或真实个人经历；
- 业务连接需要生造客户、案例或服务话术；
- 加入业务会改变原观点的自然逻辑；
- 观众尚无购买问题，本条只需认识或喜欢这个人。

## 4. 操盘手应怎样推荐

不要把选择题完全推给用户。根据素材先给判断：

```text
推荐任务：专业信任
素材形态：工作现场型
业务露出：1级
理由：这个场景最有价值的不是教老板怎么说，而是证明你能发现“聊天能说、镜头前僵”的真实问题，并给出拍摄处理。
待确认：当时老板卡在哪句话？你现场做了什么调整？调整后有什么可核实变化？
```

只有多个方向会产生明显不同成品时，才请用户选择，并同时给出首选项和取舍。

## 5. 软广不是隐藏广告

合格的“软”来自内容和业务是同一个事实，而不是把销售句藏得更深。检查：

1. 删除业务信息后，内容本身是否仍值得看？
2. 业务能力是否由真实场景、判断、过程或证据体现？
3. 是否只出现一项能力？
4. 是否突然出现服务清单、价格、夸大承诺或咨询口号？
5. 观众是否先获得理解、判断或方法，再意识到作者能提供帮助？

明显广告味包括：内容尚未成立就介绍身份、连续罗列服务、每条都要求私信、把所有话题强行转回业务、虚构客户原话或结果。

## 6. 内容组合而非单条全能

账号不应要求每条内容同时完成播放、信任和成交。阶段性比例根据账号数据调整，不使用永久固定配比。

当用户没有指定方向时，优先看近期内容缺口：

- 陌生曝光不足：补目标相关的流量型；
- 有播放但主页和关注弱：补人格/专业信任；
- 有关注和问询但顾虑反复：补转化型；
- 专业内容很多但人物单薄：补 0 级人格信任；
- 每条都像业务说明：主动降低商业露出。

没有近期排期和数据时，基于本条素材做最佳判断，并标明“未结合账号近期内容结构”。

## 7. 商业检查输出

正文之外简短标注：

- 主任务与信任子类型；
- 素材形态；
- 业务露出等级；
- 自然体现的一项能力（0 级写“无”）；
- 广告感：低 / 中 / 高，并说明触发点；
- 仍缺少的真实证据。
