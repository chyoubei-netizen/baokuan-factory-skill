# 小姜表达机制使用规则

本文件保留小姜方法中有价值的“观众感受设计”，同时避免把表达词变成机械配额。

## 1. “干货的感觉”到底是什么

观众不一定需要高密度知识点，但需要感到自己获得了东西。获得感可能来自：

- **相关感**：这说的就是我现在的处境；
- **被理解感**：有人准确说出了我没说清的问题；
- **理解感**：我终于知道为什么会这样；
- **判断感**：以后我知道该怎么分辨；
- **方法感**：我知道下一步可以怎么做；
- **自检感**：我能拿这套标准检查自己；
- **可用感**：这个表达、动作或清单能马上使用。

因此，“客户要的不是干货，是干货的感觉”不能被执行成“信息可以很水，只要塞词”。先让内容提供一种真实获得，再用语言增强感受。

## 2. 三类语言元素必须分开

### 标题关键词

用于搜索、圈人、场景、问题、结果、反差和时效。例如行业、人群、具体困境和结果词。是否有效要看样本与自有数据，不以“听起来有爆感”为证据。

### 口语表达动作

一句话在交流中承担的动作，例如：

- 拉近距离：我最近发现、说真的、你可能也遇到过；
- 提醒注意：有个细节很多人会忽略；
- 给出判断：我现在越来越觉得、这件事真正麻烦的是；
- 翻译复杂概念：说白了、换句话说；
- 制造转折：但后来我发现、问题恰恰在这里；
- 回扣前文：所以我现在再遇到这种情况……

“你知道吗”“告诉你一个真相”“其实”“说白了”“本质上”都只是可选表达动作，不是爆款暗号。

### 感觉词

用于轻微增强私密、递进、证据、反常识或情绪感，例如“私下里”“甚至”“反而”“确实”“我后来才发现”。它们不能证明观点，也不承担信息主体。

## 3. 使用原则

1. 先写事实、场景、判断和方法，再判断是否需要表达增强。
2. 不设“至少几个”、固定字数间距、每段一个、开头结尾必须有等配额。
3. 删除表达词后，核心信息仍应成立；若不成立，先补内容。
4. 同一个动作不要反复使用，避免“其实—说白了—本质上”连续堆叠。
5. 强度必须匹配证据。没有充分支撑时，少用“真相、绝对、一定、千万不要、所有人”。
6. 表达必须匹配人设。冷静理性的人可以有力度，但力度主要来自具体判断，而不是喊话。
7. 允许自然、不完整和有停顿的句子，但不能故意制造低级口癖或虚假亲密。

## 4. 乔木的人设适配

乔木适合：

- 从真实拍摄现场、客户问题、剪辑细节进入；
- 用“我最近拍了几条以后发现”“我没急着拍”“这个地方我会先确认”等平静表达；
- 先讲场景，再给明确判断，再解释原因；
- 用具体动作体现专业，例如看参考、确认用途、调整说法、检查成片。

乔木慎用：

- “告诉你一个行业真相”“老板们千万别再……”等高强度喊话；
- 没有数据却说“99%的人”；
- 连续制造焦虑或把客户写得很笨；
- 过度热情、培训导师式的“今天给大家分享三个方法”；
- 为了像真人而加入过多“你知道吧、对吧、就是说”。

高强度开头只有在事实充分、观点确实需要强提醒且符合当条语气时使用，不作为默认模板。

## 5. 如何从案例学习

案例中的词先记录为“候选表达”，再判断：

- 它完成了什么交流动作？
- 它依赖什么上下文才自然？
- 它适合什么人设和平台？
- 换一个说法能否完成同样动作？
- 是否有证据表明它优于其他表达？

学习“作用”，不要直接抄“字面”。单条爆款里出现过，不代表这个词本身已经验证。

## 6. 写后检查

逐段问：

1. 这一段新增了什么？
2. 观众得到的是相关、理解、判断、方法、自检还是可用感？
3. 表达词是否只是重复语气，没有增加交流效果？
4. 有没有把推测说成事实，或用绝对词冒充证据？
5. 读出声是否像这个人平时会说的话？

如果稿子“很顺但没东西”，补场景、事实和判断；如果“有东西但像报告”，再用口语动作拆短、转折和拉近；如果“很有情绪但不可信”，降低强度并补证据。
